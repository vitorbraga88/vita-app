# Ajustes — plano de implementação

> Executado inline (executing-plans), TDD por tarefa. Spec: `docs/superpowers/specs/2026-10-30-ajustes-design.md`.

**Goal:** `/ajustes` com 10 seções persistidas no SQLite, defaults centrais e horários em America/Recife.

**Architecture:** catálogo de chaves + validação em `src/lib/domain/configuracao/` (puro, testado);
acesso a dados só em `src/lib/db/repositories/configuracao.ts`; Server Actions em
`src/app/ajustes/actions.ts`; componentes por seção em `src/components/ajustes/`.

**Tech Stack:** Next.js 16.4.3 (App Router, Server Actions), better-sqlite3 12.11.1, Vitest 4, Playwright 1.62.

## Global Constraints

- Node `/usr/local/bin/node` v22.12.0 para todo comando (DEPLOY.md).
- Não alterar 795 séries / 36 sessões / 28 pesagens / 1 usuário / 132 exercícios.
- Sem localStorage. Sem UTC em horário salvo. Campos dependentes desabilitados, nunca escondidos.
- Nenhum arquivo > 300 linhas; SQL só em `src/lib/db/`.

### Tarefa 1 — Domínio: catálogo, horários, regras
- Create: `src/lib/domain/configuracao/{catalogo,horario,notificacao,metasAuto}.ts` + testes.
- Testes vermelhos primeiro: default de cada chave; `validarValor` rejeita fora do catálogo;
  `paraHorarioRecife("07:30") === "07:30:00-03:00"`; `agoraRecifeISO()` termina em `-03:00`;
  `podeDisparar` falso após envio real hoje e verdadeiro após só testes; TDEE/água/macros
  com valores calculados à mão.

### Tarefa 2 — Banco e repositório
- Modify: `src/lib/db/schema.sql` (tabelas `configuracao`, `notificacao_envio`).
- Create: `src/lib/db/repositories/configuracao.ts`, `scripts/migrar-configuracao.mjs`.
- Testes em banco temporário (`VITA_DB_PATH`): `getConfig` sem linha → default; com padrao
  explícito → padrao; JSON inválido → default; `setConfig` grava JSON e `atualizado_em` com
  `-03:00`; valor inválido lança; `getAllConfig` completa; histórico limitado a 20.

### Tarefa 3 — Perfil/Aparência e cutover de `/perfil`
- Remover `next-themes`, `src/app/perfil/*`, `src/components/perfil/*`, `ThemeProvider`.
- Layout aplica `data-*` do banco; tokens.css ganha `sistema`, `compacto`, `grande`, `reduzido`.
- `next.config.ts` redirect 308 `/perfil → /ajustes`; nav "Ajustes".

### Tarefa 4 — Seções restantes, ações e Dados
- 10 seções em acordeão; save-on-change + toast; dependentes desabilitados.
- Nutrição/Hidratação auto gravam em `meta`; Notificações com testar + histórico.
- Exportar (route handler), importar, limpar testes, backup manual.

### Tarefa 5 — Provas e entrega
- E2E: F5 após 3 toggles; dependentes antes/depois; 10 screenshots; console; axe em `/ajustes`.
- Produção: backup + migração, build, restart (DEPLOY.md), provas a–i, docs, commit.
